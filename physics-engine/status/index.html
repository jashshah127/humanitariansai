How deploys work

  • CI runs on every pull request and every push to main and feature-harsh.
  • Render deploys only after CI passes. A failing commit is not deployed.
  • Staging builds feature-harsh; the live service tracks main.
  • Rollback: Render, Events, Rollback to the previous deploy, then Revert the pull request on GitHub.

The recorded numbers update when python eval/status_page.py is run again and the result is pushed.
